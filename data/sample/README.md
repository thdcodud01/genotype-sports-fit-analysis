# 합성(가짜) 예시 데이터

이 폴더와 `api/ref/`의 모든 데이터는 `scripts/make_synthetic_data.py`로 만든 **가짜 데이터**입니다.
원본 프로젝트 데이터(개인 유전형, 사내 모델 계수)는 포함되어 있지 않습니다.

| 파일 | 내용 | 원본과의 관계 |
|---|---|---|
| `snp_reference.csv` | 유전자별 대립유전자와 정본 이형접합 표기 | 구조만 동일. 유전자명 G01~G24는 실제 유전자 아님 |
| `samples.csv` | 샘플 79명(타자 65, 투수 14)의 유전형 | 실존 인물 아님. 무작위 생성 |
| `coach_requirements.csv` | 수비 포지션 x 능력 코치 필수 여부(O/X) | 구조만 동일. 값은 무작위 |
| `api/ref/**` | 능력·부상 점수표, 종목 가중치표, 설정 | 구조만 동일. 계수·가중치·임계값은 무작위/예시값 |

원본에서 실제로 겪은 데이터 문제(이형접합 역순 표기, 유전자명 하이픈/언더바 차이)를
일부러 남겨 두었습니다. `python src/normalize_genotype.py`로 확인할 수 있습니다.

다시 만들기: `python scripts/make_synthetic_data.py` (seed 고정, 같은 결과)
